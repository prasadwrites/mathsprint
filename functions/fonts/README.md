Fonts used to draw the challenge score cards (functions/cards.py).

- InterDisplay-ExtraBold.otf, Inter-Medium.otf: Inter by Rasmus Andersson, SIL Open Font License 1.1 (https://github.com/rsms/inter)
- JetBrainsMono-Bold.ttf: JetBrains Mono, SIL Open Font License 1.1 (https://github.com/JetBrains/JetBrainsMono)
- NotoSans*-Bold.ttf (Devanagari, Bengali, Gurmukhi, Gujarati, Oriya, Tamil, Telugu, Kannada, Malayalam, Thai, Hebrew,
  Arabic) and NotoSansCJKsc-Bold.otf (Chinese, Japanese kana, Korean Hangul): Noto Sans by the Noto Project Authors,
  SIL Open Font License 1.1 (https://github.com/notofonts). Used for names and titles that Inter can't draw.

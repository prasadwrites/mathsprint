When a hand-written worksheet is the better choice

  • You want students to show every step on paper, so you can see where the reasoning breaks.
  • The session is offline, or the student works better away from a screen.
  • You need a diagram labeled "not drawn to scale." MathSprint draws graphs and geometry figures, but not that kind yet.

When a MathSprint deck is the better choice

  • It's the night before a session and you need fresh practice that matches today's lesson.
  • You've been burned by a wrong answer key and want every answer checked before it reaches a student.
  • You want to know how long each question took, not just whether it was right, so you know what to work on next session.
  • You're running the same test for a group and don't want to grade it by hand.

Using both

Keep your favorite worksheet and upload it: MathSprint builds a fresh deck on the same skills, in the same style. Add a focus like "only trinomials with a leading 1" to narrow it down.
